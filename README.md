# CNplus-wiki

[CNplus](https://github.com/CNplus/CNplus-lang)（中文编程语言）的**教程与文档**仓库，托管在 [wiki.cnplus.org](https://wiki.cnplus.org)。

在线阅读请直接访问 **<https://wiki.cnplus.org>**——那里有完整教程（序言 + 5 章，零基础到能写程序）、参考手册和示例索引。本仓库是它的源码。

## 目录结构

- `教程/` —— 按难度分章的完整教程（`00-开始` 序言 + 5 章）
- `参考/` —— 关键字与别名、诊断码表、运行方式、与 Python 的差异
- `示例索引.md` —— 18 个示例程序导航
- `home.md` —— wiki 首页

## 本地编辑

用 Wiki.js 或任意 Markdown 编辑器打开即可。修改后提交到 `main` 分支，wiki 站会自动同步。

## 许可

Apache-2.0（与主仓库一致）。
