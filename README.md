# CNplus —— 用中文写代码

[CNplus](https://github.com/CNplus/CNplus-lang) 是一门**中文编程语言**：关键字、类型、报错全是中文。这里放着它的**完整教程**，从零基础到能写正经程序，一步步带你走。

```cnp
设 单价 = 15
设 数量 = 4

打印("总价：" + 文本(单价 * 数量) + " 元")

如果 单价 * 数量 > 50
    打印("满 50 包邮！")
否则
    打印("再买点就包邮了")
```

## 从哪儿开始

- **完全没写过程序？** 从[快速开始](快速开始.md)出发，装好环境、跑起第一个程序。
- **想系统学一遍？** 按顺序读[教程](教程/01-变量与类型.md)，12 章由浅入深，每章都有能直接跑的代码和「练一练」。
- **写过 Python / JS？** 直接看[与 Python 的差异](参考/与Python的差异.md)，一分钟定位区别。

## 这套教程好在哪里

- 🌱 **零基础友好**：不预设任何编程经验，术语都配大白话
- ✅ **代码都能跑**：每个示例都经真实解释器验证过
- 🗣️ **一意多写**：`设`＝`令`＝`让`，用你顺口的那个
- 🔍 **三层报错**：术语 + 大白话 + 能直接照抄的改法
