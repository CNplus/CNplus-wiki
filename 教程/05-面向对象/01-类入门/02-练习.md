# 练习 · 类入门

> 学完「类、初始化、自己」，动手做一做。

## 三级练习

### 1. 照着改

写一个只有 `标题` 字段的 `书` 类，造一本书并打印标题。

<details>
<summary>参考答案</summary>

```cnp
类 书
    初始化(标题)

设 一本 = 书("小王子")
打印(一本.标题)
```

> **解析**：初始化参数会自动成为对象字段，不用手动转存。

</details>

### 2. 自己补

写 `矩形(宽, 高)`，加入返回面积的方法。

<details>
<summary>参考答案</summary>

```cnp
类 矩形
    初始化(宽, 高)
    函数 面积()
        返回 自己.宽 * 自己.高

设 一块 = 矩形(3, 4)
打印(一块.面积())      # 12
```

> **解析**：方法通过 `自己` 读取当前对象的宽和高。

</details>

### 3. 小综合

写一个「计数器」类：`初始化(起点)`，方法 `加(数)` 把起点加上数并返回结果。

<details>
<summary>参考答案</summary>

```cnp
类 计数器
    初始化(起点)
    函数 加(数)
        自己.起点 = 自己.起点 + 数
        返回 自己.起点

设 甲 = 计数器(0)
打印(甲.加(5))      # 5
打印(甲.加(3))      # 8
```

> **解析**：`初始化(起点)` 让每个计数器对象都有自己的「起点」字段（自动转存）。`加(数)` 里 `自己.起点 = 自己.起点 + 数` 把**这个对象自己的**起点加上数再存回去。`甲.加(5)` 时 `自己` 是甲，起点从 0 变 5；再 `甲.加(3)`，起点从 5 变 8。

</details>
