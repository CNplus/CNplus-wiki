# 练习 · 类进阶

> 学完「方法互调、字段可写、方法当值」，动手做一做。

## 练习

写一个「账户」类：`初始化(余额)`，方法 `存(数)` 把钱加进去、`取(数)` 把钱取出来（钱不够就返回「余额不足」）。然后造一个 `账户(100)`，存 50、取 30，打印余额。

<details>
<summary>参考答案</summary>

```cnp
类 账户
    初始化(余额)
    函数 存(数)
        自己.余额 = 自己.余额 + 数
        返回 自己.余额
    函数 取(数)
        如果 数 > 自己.余额
            返回 "余额不足"
        自己.余额 = 自己.余额 - 数
        返回 自己.余额

设 我的 = 账户(100)
打印(我的.存(50))      # 150
打印(我的.取(30))      # 120
```

> **解析**：`存(数)` 和 `取(数)` 都用 `自己.余额 = 自己.余额 ± 数` 改字段（字段可写）。`取(数)` 里先 `如果 数 > 自己.余额` 判断——钱不够就返回提示，够了才扣。这是「字段可写 + 判断」配合的典型写法。

</details>
