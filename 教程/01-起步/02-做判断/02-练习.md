## 三级练习

### 1. 照着改

设 `年龄 = 20`，满 18 岁打印“可以进入”，否则打印“还不能进入”。

<details>
<summary>参考答案</summary>

```cnp
设 年龄 = 20
如果 年龄 >= 18
    打印("可以进入")
否则
    打印("还不能进入")
```

> **解析**：条件只能回答真或假；成立走第一段，不成立走 `否则`。

</details>

### 2. 自己补

把一个数分成“正数”“零”“负数”三种情况。

<details>
<summary>参考答案</summary>

```cnp
设 数 = -3
如果 数 > 0
    打印("正数")
否则 如果 数 == 0
    打印("零")
否则
    打印("负数")
```

> **解析**：先排除正数，再单独判断零，剩下的自然是负数。

</details>

### 3. 小综合

写一个程序：判断一个数是不是偶数。

提示：偶数除以 2 的余数是 0，取余用 `%`。

<details>
<summary>参考答案</summary>

```cnp
设 数 = 8

如果 数 % 2 == 0
    打印(文本(数) + " 是偶数")
否则
    打印(文本(数) + " 是奇数")
```

> **解析**：`数 % 2` 是「数除以 2 的余数」。偶数除以 2 余 0，所以 `数 % 2 == 0` 成立就是偶数。注意是**两个**等号 `==`（判断相等），不是 `=`（赋值）。`文本(数)` 把数字转成文字才能拼接。

</details>
