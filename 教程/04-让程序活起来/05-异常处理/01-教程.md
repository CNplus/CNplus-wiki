# 异常处理

> 程序难免出错。这一章教你：出错时**主动报错**，以及**兜住**错误不让程序崩溃。

## 抛出：主动报错

发现自己处理不了的情况，用 `抛出` 喊停，带上一条说明：

```cnp
函数 安全除法(甲, 乙)
    如果 乙 == 0
        抛出 "除数不能是零"
    返回 甲 / 乙
```

`抛出` 后面跟一段说明（文字或任何值），这段说明会原样出现在捕获它的 `错` 里。`抛出` 的别名是 `报错`。抛出后程序立刻停下，除非有人「捕获」——没接住的话会报 `CN0311`。

## 尝试 / 捕获：兜住错误

不想让一个错误搞崩整个程序，就把它包在 `尝试` 里，用 `捕获` 接住：

```cnp
尝试
    设 商 = 安全除法(10, 0)
    打印(商)
捕获 错
    打印("算不了：" + 错)
```

- `尝试` 里的代码正常跑
- 一旦出错，立刻跳到 `捕获`，`错` 就是错误说明
- 没出错，`捕获` 里的内容就跳过

`捕获` 的别名是 `出错时`。

> **也可以这么写**：`抛出`/`捕获`/`最后` 各有别名（`报错`/`出错时`/`无论如何`），效果一样。这是 CNplus 的「一种意思多种写法」特性，详见[关键字与别名](../../../参考/关键字与别名.md)。

不关心错误到底是什么时，`捕获` 后面可以不写变量：

```cnp
尝试
    整数("abc")
捕获
    打印("那不是数字")
```

## 最后：无论如何都执行

有些收尾的事（关文件、清理）无论成败都要做，放 `最后`：

```cnp
尝试
    打印("开始")
    抛出 "出错了"
捕获 错
    打印("捕获：" + 错)
最后
    打印("清理完成（无论成败都执行）")
```

`最后` 段**保证执行**——哪怕 `尝试` 里 `返回` 了、或错误继续往上抛，`最后` 都会先跑完。适合放关文件、清理这类收尾。

`最后` 的别名是 `无论如何`。

## 转不了数字，就给个默认值

「文字转数字」可能失败，用异常包住就能给个默认值：

```cnp
函数 安全转数(文字, 默认 = 0)
    尝试
        返回 整数(文字)
    捕获 错
        返回 默认

打印(安全转数("42"))      # 42
打印(安全转数("abc"))     # 0（转不了，给默认）
```

完整的例子见 `示例/16-安全计算器.cnp`。

## 能接住什么错

`捕获` 能接住**运行中**出的错——除以零、类型不对、下标越界、转换失败、库调用出错、以及你自己 `抛出` 的。但**语法错误不行**：那是程序还没开始跑就发现的，抓不住。

## 对照 Python

> 学过 Python 的人，看这里——这一章学的，用 Python 写是这样。**零基础可以直接跳过**，去下面做「练一练」。

先把这一章串成一个完整程序（CNplus）：

```cnp
尝试
    整数("abc")
捕获 错
    打印("接住了：" + 错)
```

同一个程序，用 Python 写：

```python
try:                        # 尝试
    int("abc")
except Exception as 错:     # 捕获 错
    print("接住了：" + str(错))
```

| CNplus | Python |
|---|---|
| `抛出 "说明"` | `raise ValueError("说明")` |
| `尝试` | `try:` |
| `捕获 错` | `except Exception as 错:` |
| `最后` | `finally:` |
| `捕获`（不写变量） | `except:`（裸 except） |

**一个差异**：CNplus 的 `捕获` 直接接住所有运行时错误；Python 的 `except` 能按异常类型分别捕获（`except ValueError`、`except TypeError`），更精细。CNplus 简化了——新手先会「兜住」就够，分类捕获是进阶话题。
