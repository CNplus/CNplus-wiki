# 十三、类与对象

> 把「数据」和「数据的用法」绑在一起。前十二章用函数已经能写程序了，这一章给你一个更顺手的组织方式。

## 先看两种写法

同一个需求——给一个学生算等级、做名片——两种写法都能写。你更习惯哪种，就从哪种读起。

### 写法一：用字典和函数（不引入新东西）

一个学生，就是一个字典；处理学生，就是一些函数：

```cnp
设 小明 = {"名字": "小明", "分数": 92}

函数 等级(一名学生)
    如果 一名学生["分数"] >= 90
        返回 "优秀"
    否则 如果 一名学生["分数"] >= 60
        返回 "及格"
    否则
        返回 "不及格"

函数 名片(一名学生)
    返回 @"{一名学生['名字']}：{一名学生['分数']} 分（{等级(一名学生)}）"

打印(名片(小明))        # 小明：92 分（优秀）
```

这套写法你**已经会了**——字典在[第六章](06-字典.md)学过，函数在[第四章](04-造工具-函数.md)学过。数据和操作是分开的：数据装在字典里，操作是外面的函数，用的时候把数据**传进去**（`等级(小明)`）。

### 写法二：用类（数据和用法绑在一起）

```cnp
类 学生
    初始化(名字, 分数)
    函数 等级()
        如果 自己.分数 >= 90
            返回 "优秀"
        否则 如果 自己.分数 >= 60
            返回 "及格"
        否则
            返回 "不及格"
    函数 名片()
        返回 @"{自己.名字}：{自己.分数} 分（{自己.等级()}）"

设 小明 = 学生("小明", 92)
打印(小明.名片())       # 小明：92 分（优秀）
```

### 两种写法差在哪

结果一模一样，读起来不同：

| | 写法一（字典 + 函数） | 写法二（类） |
|---|---|---|
| 数据放哪 | 字典里 | 对象的「字段」里 |
| 操作放哪 | 外面的函数 | 类里面的「方法」 |
| 怎么用 | `等级(小明)`，把数据传进去 | `小明.等级()`，对象自己做事 |
| 像什么 | 工具箱和零件分开放 | 零件自带说明书 |

写法二的好处：`小明.等级()` 读起来像「小明，告诉我你的等级」——数据和它的用法**长在一起**。数据多了之后，这种「长在一起」会让代码更好读、更好改。

> **没写过面向对象**（类、对象、实例这些词）没关系，这一章从零讲。
> **写过**（比如 Python 的 class），重点看和 Python 不一样的三个地方：**初始化参数自动成字段、方法不写 self、没有继承**。

## 类是什么

**类**是「模板」，**对象**（也叫实例）是用模板造出来的具体东西。

拿「学生」打比方：

- 「学生」这个**类**是模板：它规定每个学生都有「名字」「分数」，都会「算等级」「做名片」。
- `学生("小明", 92)` 是用模板造出来的一个**具体学生**——这是对象。

```cnp
设 小明 = 学生("小明", 92)    # 小明 是对象
设 小红 = 学生("小红", 85)    # 小红 是另一个对象
```

两个对象各自独立，数据互不干扰。

## 定义类

```cnp
类 学生
    初始化(名字, 分数)
    函数 等级()
        ...
```

一个类由两部分组成：

- **`初始化(...)`**：造对象时怎么填数据。括号里的参数会**自动变成字段**（见下一节）。
- **`函数 ...()`**：这个类有哪些方法（它会的「技能」）。

`类`、`初始化` 是关键字。方法写法和普通函数一样，只是写在类里面、缩进一层。

## 初始化：参数自动成为字段

`初始化` 括号里写几个参数，对象就有几个字段，**不用手动转存**：

```cnp
类 学生
    初始化(名字, 分数)
    # 到这里，「名字」「分数」已经是字段了，不用写 自己.名字 = 名字

设 小明 = 学生("小明", 92)
打印(小明.名字)     # 小明
打印(小明.分数)     # 92
```

对比 Python：Python 要写 `self.name = name` 一行行转存；CNplus 直接省略——参数就是字段。

`初始化` 的块体**可以省略**（只造字段就够时）。要写**校验**或**派生字段**时才需要块体：

```cnp
类 学生
    初始化(名字, 分数)
        如果 分数 < 0 或 分数 > 100
            抛出 @"分数必须在 0 到 100 之间，{名字}的分数是 {分数}"
    函数 报分()
        打印(自己.分数)
```

分数不合法时，造对象当场报错（`抛出` 见[第十二章](12-异常处理.md)）。

## 自己：指代「这个方法属于的那个对象」

方法里用 **`自己`** 指代当前这个对象，然后 `.字段` 取它的字段：

```cnp
类 学生
    初始化(名字, 分数)
    函数 名片()
        返回 @"{自己.名字}：{自己.分数} 分"

设 小明 = 学生("小明", 92)
设 小红 = 学生("小红", 85)
打印(小明.名片())     # 小明：92 分
打印(小红.名片())     # 小红：85 分
```

`小明.名片()` 里，`自己` 就是小明；`小红.名片()` 里，`自己` 就是小红。同一个方法，两个对象调用，结果各用各的数据。

两个省心的地方：

- **方法签名不写 self**：Python 要写 `def 名片(self)`，CNplus 不写，`自己` 是隐式关键字。
- **`自己` 只在方法里有效**：方法外写 `自己.xxx` 会报「未声明」（CN0302）。

## 方法互调

方法里可以调用同一个对象的另一个方法，用 `自己.方法名()`：

```cnp
类 学生
    初始化(名字, 分数)
    函数 等级()
        如果 自己.分数 >= 90
            返回 "优秀"
        ...
    函数 名片()
        返回 @"{自己.名字}：{自己.分数} 分（{自己.等级()}）"   # 调用了 自己.等级()
```

## 字段可写

字段不只能读，也能改（和改字典里的值一样）：

```cnp
类 学生
    初始化(名字, 分数)
    函数 补考(新分数)
        自己.分数 = 新分数          # 直接改
    函数 过生日()
        自己.年龄 = 自己.年龄 + 1   # 复合赋值也支持
```

改的是**这个对象自己的字段**，不影响其他对象。

## 方法是一等值：可以取出来

方法可以像值一样取出来、存起来：

```cnp
类 学生
    初始化(名字)
    函数 名字大写()
        返回 大写(自己.名字)

设 小明 = 学生("xiaoming")
设 f = 小明.名字大写      # 取出方法（不带括号）
打印(f())                 # XIAOMING
```

取出时「自己」已经绑定好是哪个对象了，所以 `f()` 不用再传对象。

## 没有继承（组合优于继承）

CNplus 的类**没有继承**（不像 Python 的 `class B(A)`）。

想「复用」另一个类的能力？用**组合**——把它当字段放进来，或者把对象传进方法：

```cnp
类 班级
    初始化(名称)
        自己.成员 = []          # 字段里装一堆学生对象
    函数 加入(一名学生)
        追加(自己.成员, 一名学生)
```

「班级有一堆学生」用「班级里放一个列表、列表里装学生」来表达，而不是「班级继承列表」。这是刻意的选择：组合比继承简单、好懂，将来需要时再加。

## 什么时候用类，什么时候用字典 + 函数

不着急，两条路都通：

- **数据简单、就一两个操作**：字典 + 函数就够了，别为用类而用类。
- **数据要和操作绑一起、对象有好几个「技能」**：用类更清晰，`对象.做事()` 读起来自然。

没有谁更高级。类是一种**组织方式**，帮你在程序变大时保持条理。前十二章的写法照样对，类只是多给你一个选择。
