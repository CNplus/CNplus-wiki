# 四、造工具（函数）

> 一段代码要用好几次，就把它做成一个工具，起个名字，以后随叫随到。

## 造一个工具

```cnp
函数 打招呼(名字)
    返回 "你好，" + 名字 + "！"

打印(打招呼("小明"))    # 你好，小明！
打印(打招呼("小红"))    # 你好，小红！
```

三行读懂：

- `函数` 表示「我要造个工具」
- 括号里的 `名字` 是**占位**——用的时候填什么，它就是什么
- `返回` 表示「这个工具算出的结果是……」

## 多个参数

```cnp
函数 加法(甲, 乙)
    返回 甲 + 乙

打印(加法(3, 4))       # 7
```

## 默认参数

有的参数通常就是某个值，可以给它一个「默认」——调用时不写就用默认，写了就覆盖：

```cnp
函数 问候(名字, 招呼 = "你好")
    打印(招呼 + "，" + 名字)

问候("小明")                    # 你好，小明
问候("小刚", 招呼 = "晚上好")    # 晚上好，小刚
```

> 带默认值的参数要**排在后面**，不带默认的排前面。

## 关键字参数

调用时想「把话说清楚」或打乱顺序，就点名传参：

```cnp
函数 相除(甲, 乙)
    返回 甲 / 乙

打印(相除(乙 = 2, 甲 = 8))     # 4.0（顺序无所谓）
```

## 一次返回多个值

一个工具能一次「给出」好几个结果，接收时一口气接住：

```cnp
函数 统计(表)
    返回 长度(表), 求和(表)

设 个数, 总和 = 统计([1, 2, 3])
打印(个数)      # 3
打印(总和)      # 6
```

`返回 甲, 乙` 配合 `设 甲, 乙 = 函数()`，左边几个名字就接住几个值。

## 没有返回值的工具

有些工具只是「做一件事」，不「算出结果」。那就不用写 `返回`：

```cnp
函数 报温度(度)
    打印("今天 " + 文本(度) + " 度")

报温度(32)             # 今天 32 度
```

## 函数也是值

CNplus 里函数是「一等公民」——可以像数字、文字一样存进变量、传给别的函数：

```cnp
函数 翻倍(数)
    返回 数 * 2

设 我的工具 = 翻倍        # 把函数存进变量
打印(我的工具(5))         # 10
```

## 自己调自己：递归

函数可以在里面调用自己。经典例子是阶乘（`5! = 5 × 4 × 3 × 2 × 1`）：

```cnp
函数 阶乘(数)
    如果 数 <= 1
        返回 1
    返回 数 * 阶乘(数 - 1)

打印(阶乘(5))           # 120
```

> 递归的关键是「什么时候停」——上面的 `如果 数 <= 1 返回 1` 就是终点。没有终点会无限递归。

## 作用域：函数里和外是两个世界

函数体是**新的作用域**：

```cnp
设 名字 = "小明"

函数 换名字()
    设 名字 = "小红"     # 这是函数里的「名字」，和外面的不一样
    打印(名字)          # 小红

换名字()
打印(名字)              # 小明（外面的没被改）
```

想**修改**外面已有的变量，要用 `外部`：

```cnp
设 分数 = 60

函数 加分()
    外部 分数 = 分数 + 10

加分()
打印(分数)              # 70
```

> `外部` 的别名是 `全局`。不写 `外部` 就赋值，会变成函数里的新变量，外面的不动——这是新手最容易懵的地方。

## 练一练

写一个函数 `平方(数)` 返回 `数 * 数`，然后打印 `平方(12)`。

<details>
<summary>参考答案</summary>

```cnp
函数 平方(数)
    返回 数 * 数

打印(平方(12))     # 144
```

> **解析**：`函数 平方(数)` 造一个叫「平方」的工具，括号里的 `数` 是占位符。`返回 数 * 数` 是这个工具算出的结果。调用 `平方(12)` 时，`数` 就变成 12，于是算出 `12 * 12 = 144`。

</details>

<details>
<summary>进阶：对照 Python</summary>

```python
def 打招呼(名字):                        # 函数 打招呼(名字)
    return "你好，" + 名字 + "！"         # 返回 …

def 问候(名字, 招呼="你好"):              # 默认参数，两边一样
    print(招呼 + "，" + 名字)

def 相除(甲, 乙):                        # 关键字参数，两边一样
    return 甲 / 乙
print(相除(乙=2, 甲=8))

def 统计(表):                            # 多返回值：Python 是元组
    return len(表), sum(表)
个数, 总和 = 统计([1, 2, 3])
```

| CNplus | Python |
|---|---|
| `函数 f(x)` | `def f(x):`（结尾要冒号） |
| `返回 x` | `return x` |
| `返回 甲, 乙` | `return 甲, 乙`（其实是返回元组） |
| `外部 x = …` | `global x` |
| 函数也是值 | 一样（Python 函数也是一等公民） |

**作用域差异**：CNplus 里 `如果`/`循环` 的主体也是新作用域；Python **只有函数**有作用域，`if`/`while` 里的变量在外面也能访问。

</details>
