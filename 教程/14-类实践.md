# 十四、类的实践：做一个记账本

> 这一章不学新语法，把前面学的**全部串起来**，做一个真的能用的程序：记账本。
> 我会一行行带着你写。写之前先看它长什么样，再拆开讲。

## 成品长什么样

运行起来是这样的（`>` 后面是你输入的内容）：

```
> 工资
> 8000
> 收入
工资｜收入｜8000 元
> 房租
> 2000
> 支出
工资｜收入｜8000 元
房租｜支出｜2000 元
结余：6000 元
```

它能：记一笔账（名称、金额、收入还是支出）、看流水、算结余。看着简单，但它把前面十二章的东西几乎全用上了。

## 先想清楚：数据长什么样

记账，核心是一个个「账目」。一个账目有三个信息：

- **名称**——这笔钱是干嘛的（"工资"、"房租"）
- **金额**——多少钱
- **种类**——"收入" 还是 "支出"

这些信息捆在一起，正好用[上一章](13-类与对象.md)学的**类**来表示。先造「账目」这个零件：

```cnp
类 账目
    初始化(名称, 金额, 种类)
        如果 金额 <= 0
            抛出 @"金额必须大于 0，{名称}的金额是 {金额}"
    函数 描述()
        返回 @"{自己.名称}｜{自己.种类}｜{自己.金额} 元"
```

逐行看：

- `类 账目` —— 造一个叫「账目」的模板
- `初始化(名称, 金额, 种类)` —— 造账目时要给这三个值，它们**自动成为字段**（不用写 `自己.名称 = 名称`）
- `如果 金额 <= 0` 里的 `抛出` —— 这是[第十二章](12-异常处理.md)的异常：金额必须正数，否则当场喊停。这条是**校验**，防止你记一笔「-5 元」的糊涂账
- `描述()` —— 方法，把账目变成一行文字，用 `@` 格式串（[第九章](09-输入输出.md)）

验证一下零件能不能用：

```cnp
设 一笔 = 账目("工资", 8000, "收入")
打印(一笔.描述())        # 工资｜收入｜8000 元
```

## 再造「记账本」：装一堆账目

现在要一个东西能**装下很多账目**。用[第十三章](13-类与对象.md)讲的「组合」——记账本里放一个列表：

```cnp
类 记账本
    初始化()
        自己.条目 = []
    函数 记一笔(名称, 金额, 种类)
        追加(自己.条目, 账目(名称, 金额, 种类))
```

- `初始化()` 没有参数，但**块体不能省**——这里要造一个字段 `自己.条目 = []`（一个空列表）
- `记一笔` 方法：造一个新账目，用 `追加`（[第五章](05-列表.md)）塞进列表

## 算结余：遍历 + 判断

结余 = 所有收入之和 − 所有支出之和。要「把所有条目过一遍」，是[第七章](07-遍历.md)的活：

```cnp
    函数 结余()
        设 收入 = 0
        设 支出 = 0
        遍历 自己.条目 每个 条
            如果 条.种类 == "收入"
                收入 = 收入 + 条.金额
            否则
                支出 = 支出 + 条.金额
        返回 收入 - 支出
```

- `遍历 自己.条目 每个 条` —— 把每个账目轮流交给 `条`
- `条.种类`、`条.金额` —— 取这个账目对象的字段（`.` 就像字典的 `["标签"]`，见[第六章](06-字典.md)）
- `如果…否则…` —— [第二章](02-做判断.md)的分支
- `收入 = 收入 + 条.金额` —— 累加。也可以写成 `收入 += 条.金额`（[第三章](03-重复做.md)的复合赋值）

## 看流水：空列表要特殊处理

```cnp
    函数 看流水()
        如果 长度(自己.条目) == 0
            打印("还没有账目")
            返回
        遍历 自己.条目 每个 条
            打印(条.描述())
```

`长度(...)` 是[第八章](08-内置函数.md)的内置函数。这里先判断「一本空账本」，给个友好提示，而不是啥都不打。

## 按种类汇总：字典 + 复合赋值

想一眼看出「收入总共多少、支出总共多少」，用[第六章](06-字典.md)的字典按种类归拢：

```cnp
    函数 按种类汇总()
        设 汇总 = {}
        遍历 自己.条目 每个 条
            如果 有标签(汇总, 条.种类)
                汇总[条.种类] += 条.金额
            否则
                汇总[条.种类] = 条.金额
        返回 汇总
```

逐行拆：

- `设 汇总 = {}` —— 一个空字典，将来是 `{"收入": 8500, "支出": 2300}` 这种
- `有标签(汇总, 条.种类)` —— 这个种类在汇总里**已经有过**吗？
- **有过** → `汇总[条.种类] += 条.金额`，往已有的数上累加（这是[第三章](03-重复做.md)学的「索引复合赋值」）
- **没有** → `汇总[条.种类] = 条.金额`，第一次出现，先建一个

这正是[第六章](06-字典.md)讲的「分组计数」套路，只是把「计数」换成了「累计金额」。

## 最近几笔：切片

想只看最近几笔账，用[第五章](05-列表.md)的**负索引切片**：

```cnp
    函数 最近几笔(数量)
        返回 自己.条目[-数量:]
```

`自己.条目[-数量:]` 从倒数第 `数量` 个取到末尾。比如 `[-2:]` 就是最后两笔。不用数列表多长，负数自动从尾巴数。

## 拼起来：完整代码

把上面的方法都塞进 `类 记账本`，加上开头造账本、末尾演示：


## 让它能「对话」：加输入

上面的账是**写死在代码里**的。想让使用者自己输入，用[第九章](09-输入输出.md)的 `询问` / `询问数值`：

```cnp
设 本子 = 记账本()

设 名称 = 询问("名称：")
设 金额 = 询问数值("金额：")
设 种类 = 询问("种类（收入/支出）：")

本子.记一笔(名称, 金额, 种类)
本子.看流水()
打印(@"结余：{本子.结余()} 元")
```

运行时会停下来等你敲字。`询问数值` 拿回来的是**数字**，输错还会自动重问。

## 兜住错误：尝试 / 捕获

如果使用者输入金额 `-5`，`账目` 的初始化会 `抛出` 异常，程序当场崩。用[第十二章](12-异常处理.md)的 `尝试/捕获` 兜住：

```cnp
尝试
    本子.记一笔(名称, 金额, 种类)
    本子.看流水()
捕获 错
    打印("记不了：" + 错)
```

现在输入 `-5`，程序不会崩，而是打印：

```
记不了：金额必须大于 0，白条的金额是 -5
```

看——你这一章写下的 `抛出`，在这里被 `捕获` 接住了。异常处理的两半（抛出 + 捕获）就这么配合起来了。

## 对照 Python

> 学过 Python 的人，看这里——这个记账本，用 Python 的 class 写是这样。**零基础可以直接跳过**，去下面做「练一练」。

```python
class 账目:                      # 类 账目
    def __init__(self, 名称, 金额, 种类):   # 初始化
        if 金额 <= 0:
            raise ValueError(f"金额必须大于 0，{名称}的金额是 {金额}")   # 抛出
        self.名称 = 名称           # ← Python 要一行行写，CNplus 自动
        self.金额 = 金额
        self.种类 = 种类

    def 描述(self):               # 函数 描述()
        return f"{self.名称}｜{self.种类}｜{self.金额} 元"   # @ 格式串 → f-string
```

对照几个关键点：

| CNplus | Python |
|---|---|
| `类 账目` | `class 账目` |
| `初始化(名称, 金额)`（参数自动成字段） | `def __init__(self, 名称, 金额)` + 手动 `self.名称 = 名称` |
| `自己.名称` | `self.名称` |
| `@"…{自己.名称}…"` | `f"…{self.名称}…"` |
| `抛出 "说明"` | `raise ValueError("说明")` |

最大的区别还是[上一章](13-类与对象.md)说的那三条：**初始化参数自动成字段、方法不写 self、没有继承**。会用 CNplus 写这个记账本，转 Python 只差「手动写 `self.xxx = xxx`」这一步。

## 练一练

给「记账本」加一个方法 `总收入()`，返回所有「收入」类账目的金额之和（别抄结余里的代码，单独写一个方法）。

<details>
<summary>参考答案</summary>

```cnp
函数 总收入()
    设 总 = 0
    遍历 自己.条目 每个 条
        如果 条.种类 == "收入"
            总 = 总 + 条.金额
    返回 总
```

> **解析**：这和 `结余()` 的前半段几乎一样——遍历所有条目，只把 `种类 == "收入"` 的累加起来。`总 = 总 + 条.金额` 是第三章的累加模式。注意 `设 总 = 0` 在遍历**之前**，累加要有个起点。
