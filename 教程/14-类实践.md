# 十四、类的实践：做一个购物车

> [上一章](13-类与对象.md)学了类是什么。这一章动手做个小项目，把类用起来。
> 结尾还是老规矩：同一个需求，用类、用字典+函数各写一遍，对比着看。

## 要做什么

一个**购物车**：往里面放商品、算总价、打印小票。

看起来简单，但它能把类的几个要点都用上：

- 商品有「名称」「单价」—— 用**初始化**自动变成字段
- 购物车里装一堆商品 —— 用**组合**（一个类里面放另一个类）
- 算总价要逐个累加 —— 用**遍历** + 访问字段
- 打印小票要调总价 —— 用**方法互调**

## 第一步：先造「商品」这个零件

```cnp
类 商品
    初始化(名称, 单价)
    函数 描述()
        返回 @"{自己.名称}（{自己.单价} 元）"
```

读一下：`商品("苹果", 3)` 造出一个商品，`名称`、`单价` 自动成了字段；`描述()` 是它的方法，输出一行文字。

```cnp
设 苹果 = 商品("苹果", 3)
打印(苹果.描述())        # 苹果（3 元）
```

## 第二步：再造「购物车」——组合

购物车要能「装」商品。做法是：购物车有个字段 `条目`，是个空列表，往里面装商品：

```cnp
类 购物车
    初始化()
        自己.条目 = []
    函数 加入(一件商品, 数量)
        追加(自己.条目, [一件商品, 数量])
```

注意两处：

- `初始化()` 括号里**没有参数**，但块体不能省——这里要造一个派生字段 `自己.条目 = []`（一个空列表）。
- 每个「条目」是 `[商品, 数量]` 这样一个小列表：买了什么、买了几个，捆在一起。

「购物车里有一堆商品」用「购物车放一个列表、列表里装商品」来表达，这就是**组合**——不是继承，是把对象当数据放进去。

```cnp
设 车 = 购物车()
车.加入(商品("苹果", 3), 4)     # 苹果 4 个
车.加入(商品("面包", 8), 1)     # 面包 1 个
```

## 第三步：算总价——遍历 + 字段

总价 = 每个条目「单价 × 数量」加起来：

```cnp
类 购物车
    初始化()
        自己.条目 = []
    函数 加入(一件商品, 数量)
        追加(自己.条目, [一件商品, 数量])
    函数 总价()
        设 合计 = 0
        遍历 自己.条目 每个 条目
            设 一件 = 条目[0]     # 商品对象
            设 数 = 条目[1]       # 数量
            合计 = 合计 + 一件.单价 * 数
        返回 合计
```

`一件.单价` 就是取「这个商品对象」的字段——和取字典的值一样，只是用 `.` 不用 `["单价"]`。

## 第四步：打印小票——方法互调

```cnp
    函数 小票()
        遍历 自己.条目 每个 条目
            打印(@"{条目[0].描述()} × {条目[1]}")
        打印(@"合计：{自己.总价()} 元")
```

`自己.总价()` 是**方法调用方法**——小票方法里调了总价方法，不用重复算总价的代码。

## 完整代码

```cnp
类 商品
    初始化(名称, 单价)
    函数 描述()
        返回 @"{自己.名称}（{自己.单价} 元）"

类 购物车
    初始化()
        自己.条目 = []
    函数 加入(一件商品, 数量)
        追加(自己.条目, [一件商品, 数量])
    函数 总价()
        设 合计 = 0
        遍历 自己.条目 每个 条目
            设 一件 = 条目[0]
            设 数 = 条目[1]
            合计 = 合计 + 一件.单价 * 数
        返回 合计
    函数 小票()
        遍历 自己.条目 每个 条目
            打印(@"{条目[0].描述()} × {条目[1]}")
        打印(@"合计：{自己.总价()} 元")

设 车 = 购物车()
车.加入(商品("苹果", 3), 4)
车.加入(商品("面包", 8), 1)
车.小票()
```

运行输出：

```
苹果（3 元） × 4
面包（8 元） × 1
合计：20 元
```

## 对照：不用类，用字典 + 函数

同一个购物车，不碰类，用你已经会的字典和函数也能写：

```cnp
设 车 = []      # 每个条目是 [字典, 数量]

函数 加入(车, 名称, 单价, 数量)
    追加(车, [{"名称": 名称, "单价": 单价}, 数量])

函数 总价(车)
    设 合计 = 0
    遍历 车 每个 条目
        合计 = 合计 + 条目[0]["单价"] * 条目[1]
    返回 合计

函数 小票(车)
    遍历 车 每个 条目
        打印(@"{条目[0]['名称']}（{条目[0]['单价']} 元） × {条目[1]}")
    打印(@"合计：{总价(车)} 元")

加入(车, "苹果", 3, 4)
加入(车, "面包", 8, 1)
小票(车)
```

输出**一模一样**。差别在写法：

| | 字典 + 函数 | 类 |
|---|---|---|
| 商品怎么表示 | `{"名称":…, "单价":…}` 一个字典 | `商品("苹果", 3)` 一个对象 |
| 取单价 | `条目[0]["单价"]` | `一件.单价` |
| 算总价 | `总价(车)`，把车传进去 | `自己.总价()`，车自己算 |
| 数据放哪 | 散在字典里，函数在外面 | 数据和用法长在类里 |

看 `条目[0]["单价"]` 和 `一件.单价` 的差别——后者少了两个引号、两个括号，读起来顺得多。程序一大，这种「顺」会越来越值钱。

## 加个新功能试试

给购物车加「清空」，体会一下**在类里加功能**有多顺手——只在类里面加一个方法：

```cnp
    函数 清空()
        自己.条目 = []
```

对比字典写法，要加一个 `清空(车)` 函数，还要记得调用时把 `车` 传进去。类的版本，`车.清空()` 就够了。

## 练一练

给「商品」类加一个方法 `涨价(幅度)`，把单价加上幅度，返回新单价。然后用它把苹果从 3 元涨到 3.5 元。

<details>
<summary>参考答案</summary>

```cnp
类 商品
    初始化(名称, 单价)
    函数 涨价(幅度)
        自己.单价 = 自己.单价 + 幅度
        返回 自己.单价
    函数 描述()
        返回 @"{自己.名称}（{自己.单价} 元）"

设 苹果 = 商品("苹果", 3)
打印(苹果.涨价(0.5))      # 3.5
打印(苹果.描述())         # 苹果（3.5 元）
```

</details>
