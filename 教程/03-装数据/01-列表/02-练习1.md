# 练习一 · 列表入门

> 学完「建列表、索引、负索引、改值、嵌套」，动手做一做。

## 三级练习

### 1. 照着改

从 `["甲", "乙", "丙"]` 中打印第一个和最后一个元素。

<details>
<summary>参考答案</summary>

```cnp
设 名单 = ["甲", "乙", "丙"]
打印(名单[0])       # 甲
打印(名单[-1])      # 丙
```

> **解析**：`0` 是第一个位置，`-1` 从尾巴数第一个。

</details>

### 2. 自己补

把 `[80, 90, 70]` 的第二个分数改成 95。

<details>
<summary>参考答案</summary>

```cnp
设 分数们 = [80, 90, 70]
分数们[1] = 95
打印(分数们)        # [80, 95, 70]
```

> **解析**：第二个元素的编号是 1；给这个位置赋值会改动原列表。

</details>

### 3. 小综合

写一个程序：建购物清单 `["苹果", "香蕉", "橙子"]`，把第二项改成 `"草莓"`，再打印第一项、最后一项和完整清单。

<details>
<summary>参考答案</summary>

```cnp
设 清单 = ["苹果", "香蕉", "橙子"]
清单[1] = "草莓"
打印(清单[0])           # 苹果
打印(清单[-1])          # 橙子
打印(清单)              # [苹果, 草莓, 橙子]
```

> **解析**：`清单[1]` 是第二项，赋值后原列表会改变；`清单[0]` 取第一项，`清单[-1]` 从尾巴取最后一项。

</details>
