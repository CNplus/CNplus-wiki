# 练习一 · 列表入门

> 学完「建列表、索引、负索引、改值、嵌套」，动手做一做。

## 练习

写一个程序：建一个购物清单 `["苹果", "香蕉"]`，往末尾追加 `"橙子"`，再打印它和它的长度。

<details>
<summary>参考答案</summary>

```cnp
设 清单 = ["苹果", "香蕉"]
追加(清单, "橙子")
打印(清单)              # [苹果, 香蕉, 橙子]
打印(长度(清单))        # 3
```

> **解析**：`追加(清单, "橙子")` 把 "橙子" 加进列表**末尾**（它直接改原列表，不用重新赋值）。`长度(清单)` 数出列表里有几个元素——加完橙子后是 3 个。

</details>
