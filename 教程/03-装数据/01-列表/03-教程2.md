# 列表进阶

> 入门会建列表、取元素了。这一节学切片、以及改列表的各种函数。

## 切一段：切片

用 `[起:止]` 从列表里切一段，**含起点、不含终点**（左闭右开）：

```cnp
设 数们 = [1, 2, 3, 4, 5]

打印(数们[1:3])          # [2, 3]（第 1、2 号，不含第 3 号）
打印(数们[2:])           # [3, 4, 5]（从第 2 号到结尾）
打印(数们[:2])           # [1, 2]（从头到第 2 号前）
打印(数们[:])            # [1, 2, 3, 4, 5]（整个，等于复制一份）
```

- 起、止都能省略：`[2:]` 到结尾、`[:2]` 从头、`[:]` 整个。
- 负数从尾巴数：`数们[-2:]` 是最后两个、`数们[:-1]` 是去掉最后一个。
- **越界不报错**：`数们[1:99]` 等于 `数们[1:]`——切一段，段短了没关系。这跟单个索引越界报错是**刻意不一样**：单索引是「取一个具体位置」，位置不存在就该报错；切片是「取一段」，能取多少取多少。
- 起比止大得空列表：`数们[2:1]` 得 `[]`。

字符串也能切片：`"你好世界"[1:3]` 得 `"好世"`。

切片是**复制出一段新的**，改切片不影响原来的列表：

```cnp
设 数们 = [1, 2, 3]
设 前两个 = 数们[:2]
追加(前两个, 99)
打印(数们)              # [1, 2, 3]（没变）
打印(前两个)            # [1, 2, 99]
```

## 改列表的内置函数

| 函数 | 作用 | 例子 |
|---|---|---|
| `追加(表, 项)` | 末尾加一个 | `追加(同学们, "小美")` |
| `插入(表, 位, 项)` | 插到指定位置 | `插入(同学们, 1, "小丽")` |
| `移除(表, 项)` | 删掉某个值 | `移除(同学们, "小红")` |
| `弹出(表)` | 拿走最后一个 | `设 最后 = 弹出(同学们)` |
| `弹出(表, 位)` | 拿走指定位置 | `弹出(同学们, 0)` |

```cnp
设 名单 = ["甲", "乙", "丙"]

追加(名单, "丁")
打印(名单)          # [甲, 乙, 丙, 丁]

插入(名单, 1, "插队")
打印(名单)          # [甲, 插队, 乙, 丙, 丁]

设 拿走的 = 弹出(名单)
打印(拿走的)        # 丁
打印(名单)          # [甲, 插队, 乙, 丙]
```

> `追加`、`插入`、`移除`、`弹出` 会**直接改原列表**；而 `排序`、`倒序` 是**返回一个新列表**，原列表不动。

## 另一种写法：点调用

这些函数也能「挂」在列表上点出来，效果完全一样，读起来更像一句话：

```cnp
设 名单 = ["甲", "乙"]

名单.追加("丙")        # 等价于 追加(名单, "丙")
打印(名单)            # [甲, 乙, 丙]

打印(名单.长度())      # 等价于 长度(名单) → 3
```

> **也可以这么写**：`名单.追加(x)` 和 `追加(名单, x)` 是同一个函数的两种写法，字典、字符串的内置函数也都能点调用。这是 CNplus 的特性（成员方法），详见[关键字与别名](../../../参考/关键字与别名.md)。

## 排序、倒序、包含、连接

```cnp
设 数们 = [3, 1, 2]

打印(排序(数们))          # [1, 2, 3]   （返回新列表）
打印(数们)               # [3, 1, 2]   （原列表没变）

打印(倒序(数们))          # [2, 1, 3]
打印(包含(数们, 2))       # 真
打印(包含(数们, 9))       # 假

打印(连接(数们, "-"))     # "3-1-2"（连成一条文字）
```

## 长度

```cnp
设 同学们 = ["小明", "小红", "小刚"]
打印(长度(同学们))        # 3
```

## 对照 Python

> 学过 Python 的人，看这里——这一节学的，用 Python 写是这样。**零基础可以直接跳过**，去下面做「练习二」。

先把这一节串成一个完整程序（CNplus）：

```cnp
设 数们 = [1, 2, 3]
追加(数们, 4)
打印(数们[0])       # 第一个
打印(数们[-1])      # 最后一个
打印(数们[1:3])     # 切片
```

同一个程序，用 Python 写：

```python
数们 = [1, 2, 3]
数们.append(4)          # 追加(数们, 4)
print(数们[0])          # 第一个
print(数们[-1])         # 最后一个
print(数们[1:3])        # 切片，语法完全一致
```

| CNplus | Python |
|---|---|
| `追加(表, 项)` | `表.append(项)` |
| `插入(表, 位, 项)` | `表.insert(位, 项)` |
| `移除(表, 项)` | `表.remove(项)` |
| `弹出(表)` | `表.pop()` |
| `长度(表)` | `len(表)` |
| `包含(表, 项)` | `项 in 表` |
| `表.追加(x)` | `表.append(x)`（点调用就是 Python 风格） |

切片、负索引两边几乎一模一样。列表函数 CNplus 有两种写法（`追加(表, 项)` 或 `表.追加(项)`），Python 只有点调用一种。
