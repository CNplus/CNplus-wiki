# 练习二 · 列表进阶

> 学完「切片、内置函数、点调用、排序」，动手做一做。

## 练习

写一个程序，完成四件事：

1. 设 `数们 = [1, 2, 3, 4, 5, 6, 7]`，打印 `数们[1:4]`（第 2 到第 4 个）和 `数们[-2:]`（最后两个）。
2. 用 `数们[::2]` 从头开始隔一项取一个。
3. 把文字 `"一二三四五"` 倒着取。
4. 最后再打印 `数们`，确认切片没有改动原列表。

<details>
<summary>参考答案</summary>

```cnp
设 数们 = [1, 2, 3, 4, 5, 6, 7]

打印(数们[1:4])          # [2, 3, 4]
打印(数们[-2:])          # [6, 7]
打印(数们[::2])          # [1, 3, 5, 7]
打印("一二三四五"[::-1])  # 五四三二一
打印(数们)               # [1, 2, 3, 4, 5, 6, 7]
```

> **解析**：`数们[1:4]` 是「从下标 1 到下标 4 之前」；`数们[-2:]` 从倒数第 2 个取到结尾；`数们[::2]` 从位置 0 出发，每次向右走 2 格，所以取到 1、3、5、7。`[::-1]` 的步长是 `-1`，会从末尾向左走，用来倒着取。最后的 `数们` 没变，因为切片得到的是新值。

</details>
