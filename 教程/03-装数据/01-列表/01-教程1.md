# 列表入门

> 一个名字装一串东西。这是从「写玩具」到「写正经程序」的分水岭。

## 什么是列表

```cnp
设 同学们 = ["小明", "小红", "小刚"]
打印(同学们)              # [小明, 小红, 小刚]
```

方括号 `[]` 里放一串东西，用逗号隔开，就是一个列表。

## 取某一个：索引

列表里的东西有编号，**从 0 开始**：

```cnp
设 同学们 = ["小明", "小红", "小刚"]

打印(同学们[0])          # 小明（第 1 个）
打印(同学们[1])          # 小红（第 2 个）
打印(同学们[2])          # 小刚（第 3 个）
```

> ⚠️ 编号从 **0** 开始，不是 1。这是新手最容易错的地方。为什么从 0？这是几乎所有编程语言的约定——第 1 个是 0 号，第 2 个是 1 号……习惯就好。

## 从尾巴数：负索引

想取**最后一个**，不用先数长度，用负数从尾巴往前数：

```cnp
设 同学们 = ["小明", "小红", "小刚"]

打印(同学们[-1])         # 小刚（倒数第 1 个）
打印(同学们[-2])         # 小红（倒数第 2 个）
```

字符串也能这样取：`"你好"[-1]` 得 `"好"`。

> ⚠️ 负数一样要落在范围内。长度 3 的列表，`[-4]` 就报 `CN0308`（越界）。

## 改某一个

```cnp
设 分数们 = [80, 90, 70]
分数们[1] = 95           # 把第 2 个改成 95
打印(分数们)              # [80, 95, 70]
```

## 列表里能装列表

```cnp
设 表格 = [[1, 2], [3, 4], [5, 6]]
打印(表格[1][0])         # 3（第 2 行第 1 个）
```


## 对照 Python

> 学过 Python 的人看，零基础可跳过。

先看一个完整的 CNplus 程序：

```cnp
设 颜色 = ["红", "绿", "蓝"]
颜色[1] = "黄"
打印(颜色[0])
打印(颜色[-1])
打印(颜色)
```

同一个程序，用 Python 写：

```python
颜色 = ["红", "绿", "蓝"]
颜色[1] = "黄"
print(颜色[0])
print(颜色[-1])
print(颜色)
```

| CNplus | Python |
|---|---|
| `设 颜色 = [...]` | `颜色 = [...]` |
| `颜色[0]`、`颜色[-1]` | 写法相同 |
| `颜色[1] = "黄"` | 写法相同，都会改动原列表 |
| `打印(颜色)` 显示 `[红, 黄, 蓝]` | `print(颜色)` 显示 `['红', '黄', '蓝']`；数据相同，文字元素的显示格式不同 |
