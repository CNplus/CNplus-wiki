# 练习一 · 函数入门

> 学完「造工具、多个参数、默认参数、关键字参数」，动手做一做。做完点开参考答案对一对。

## 三级练习

### 1. 照着改

写一个 `欢迎(名字)` 函数，返回 `"欢迎，" + 名字`。

<details>
<summary>参考答案</summary>

```cnp
函数 欢迎(名字)
    返回 "欢迎，" + 名字

打印(欢迎("小明"))
```

> **解析**：参数是调用时填入的值，`返回` 把拼好的文字交回调用处。

</details>

### 2. 自己补

写一个函数 `平方(数)` 返回 `数 * 数`，然后打印 `平方(12)`。

<details>
<summary>参考答案</summary>

```cnp
函数 平方(数)
    返回 数 * 数

打印(平方(12))     # 144
```

> **解析**：调用 `平方(12)` 时，参数 `数` 变成 12，函数返回 `12 * 12`。

</details>

### 3. 小综合

写一个 `总价(单价, 数量 = 1)` 函数，让数量可以省略，也能把两个值都按参数名传入。

<details>
<summary>参考答案</summary>

```cnp
函数 总价(单价, 数量 = 1)
    返回 单价 * 数量

打印(总价(8))                             # 8（全按位置）
打印(总价(单价 = 8, 数量 = 3))             # 24（全按名字）
```

> **解析**：不传数量时用默认值 1；按名字传值时，`单价` 和 `数量` 都要写出来。自定义函数的一次调用只能全按位置或全按名字，不能混写。

</details>
