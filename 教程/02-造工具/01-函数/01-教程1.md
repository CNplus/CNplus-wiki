# 函数入门

> 一段代码要用好几次，就把它做成一个工具，起个名字，以后随叫随到。

## 造一个工具

```cnp
函数 打招呼(名字)
    返回 "你好，" + 名字 + "！"

打印(打招呼("小明"))    # 你好，小明！
打印(打招呼("小红"))    # 你好，小红！
```

三行读懂：

- `函数` 表示「我要造个工具」
- 括号里的 `名字` 是**占位**——用的时候填什么，它就是什么
- `返回` 表示「这个工具算出的结果是……」

## 多个参数

```cnp
函数 加法(甲, 乙)
    返回 甲 + 乙

打印(加法(3, 4))       # 7
```

## 默认参数

有的参数通常就是某个值，可以给它一个「默认」——调用时不写就用默认，写了就覆盖：

```cnp
函数 问候(名字, 招呼 = "你好")
    打印(招呼 + "，" + 名字)

问候("小明")                    # 你好，小明
问候("小刚", 招呼 = "晚上好")    # 晚上好，小刚
```

> 带默认值的参数要**排在后面**，不带默认的排前面。

## 关键字参数

调用时想「把话说清楚」或打乱顺序，就点名传参：

```cnp
函数 相除(甲, 乙)
    返回 甲 / 乙

打印(相除(乙 = 2, 甲 = 8))     # 4.0（顺序无所谓）
```

> **也可以这么写**：`函数` 的别名有 `定义`、`过程`，`返回` 的别名有 `返`、`给出`。这是 CNplus 的「一种意思多种写法」特性，详见[关键字与别名](../../../参考/关键字与别名.md)。
