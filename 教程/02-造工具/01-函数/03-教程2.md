# 函数进阶

> 入门会造简单工具了。这一节学更高级的用法：多返回值、函数当值用、递归、作用域。

## 一次返回多个值

一个工具能一次「给出」好几个结果，接收时一口气接住：

```cnp
函数 统计(表)
    返回 长度(表), 求和(表)

设 个数, 总和 = 统计([1, 2, 3])
打印(个数)      # 3
打印(总和)      # 6
```

`返回 甲, 乙` 配合 `设 甲, 乙 = 函数()`，左边几个名字就接住几个值。

## 没有返回值的工具

有些工具只是「做一件事」，不「算出结果」。那就不用写 `返回`：

```cnp
函数 报温度(度)
    打印("今天 " + 文本(度) + " 度")

报温度(32)             # 今天 32 度
```

## 函数也是值

CNplus 里函数是「一等公民」——可以像数字、文字一样存进变量、传给别的函数：

```cnp
函数 翻倍(数)
    返回 数 * 2

设 我的工具 = 翻倍        # 把函数存进变量
打印(我的工具(5))         # 10
```

## 自己调自己：递归

函数可以在里面调用自己。经典例子是阶乘（`5! = 5 × 4 × 3 × 2 × 1`）：

```cnp
函数 阶乘(数)
    如果 数 <= 1
        返回 1
    返回 数 * 阶乘(数 - 1)

打印(阶乘(5))           # 120
```

> 递归的关键是「什么时候停」——上面的 `如果 数 <= 1 返回 1` 就是终点。没有终点会无限递归。

## 作用域：函数里和外是两个世界

函数体是**新的作用域**：

```cnp
设 名字 = "小明"

函数 换名字()
    设 名字 = "小红"     # 这是函数里的「名字」，和外面的不一样
    打印(名字)          # 小红

换名字()
打印(名字)              # 小明（外面的没被改）
```

想**修改**外面已有的变量，要用 `外部`：

```cnp
设 分数 = 60

函数 加分()
    外部 分数 = 分数 + 10

加分()
打印(分数)              # 70
```

> **也可以这么写**：`外部` 的别名是 `全局`。不写 `外部` 就赋值，会变成函数里的新变量，外面的不动——这是新手最容易懵的地方。别名详见[关键字与别名](../../../参考/关键字与别名.md)。

## 对照 Python

> 学过 Python 的人，看这里——这一节学的，用 Python 写是这样。**零基础可以直接跳过**，去下面做「练习二」。

先把这一节串成一个完整程序（CNplus）：

```cnp
函数 阶乘(数)
    如果 数 <= 1
        返回 1
    返回 数 * 阶乘(数 - 1)

打印(阶乘(5))
```

同一个程序，用 Python 写：

```python
def 阶乘(数):                    # 函数 阶乘(数)（结尾冒号）
    if 数 <= 1:
        return 1                 # 返回 1
    return 数 * 阶乘(数 - 1)

print(阶乘(5))
```

| CNplus | Python |
|---|---|
| `函数 f(x)` | `def f(x):`（结尾冒号） |
| `返回 x` | `return x` |
| `返回 甲, 乙` | `return 甲, 乙`（其实是返回元组） |
| `外部 x = …` | `global x` |
| 函数也是值 | 一样（Python 函数也是一等公民） |

**作用域差异**：CNplus 里 `如果`/`循环` 的主体也是新作用域；Python **只有函数**有作用域，`if`/`while` 里的变量在外面也能访问。
