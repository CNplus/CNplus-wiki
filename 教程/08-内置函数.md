# 八、内置函数速查

> CNplus 自带 **36 个内置函数**，不用导入直接能用。按用途分七类，全列在这里。

## 输出与类型

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `打印(…)` | 显示到屏幕（多个用空格连） | `打印(1, 2, 3)` | `1 2 3` |
| `类型(值)` | 查类型名 | `类型("你好")` | `字符串` |
| `文本(值)` | 转成文字 | `文本(真)` | `"真"` |
| `整数(值)` | 转成整数 | `整数("5")` | `5` |
| `小数(值)` | 转成小数 | `小数("3.14")` | `3.14` |

`类型()` 能认出八种：`整数` `小数` `字符串` `布尔` `空` `列表` `字典` `函数`。

## 输入

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `询问(提示)` | 读一行文字（提示语可省略） | `询问("名字？")` | 你输入的文字 |
| `询问数值(提示)` | 读一个数字，输错自动重问 | `询问数值("年龄？")` | 你输入的数字 |

（详见[第九章：输入输出](09-输入输出.md)。）

## 通用

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `长度(值)` | 数一数有多少个 | `长度([1,2,3])` / `长度("你好")` | `3` / `2` |
| `范围(…)` | 造一串数字（见第七章） | `范围(1, 6)` | `[1,2,3,4,5]` |
| `随机数(小, 大)` | 随机整数（含两端） | `随机数(1, 6)` | 掷骰子 |

## 数学

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `绝对值(数)` | 去掉负号 | `绝对值(-5)` | `5` |
| `最大(…)` | 取最大的 | `最大(3, 1, 2)` 或 `最大([3,1,2])` | `3` |
| `最小(…)` | 取最小的 | `最小([3,1,2])` | `1` |
| `求和(列表)` | 加起来 | `求和([1,2,3])` | `6` |
| `四舍五入(数)` | 四舍五入 | `四舍五入(3.14159, 2)` | `3.14` |
| `平方根(数)` | 开平方 | `平方根(16)` | `4.0` |

## 列表

| 函数 | 作用 | 是否改原列表 |
|---|---|---|
| `追加(表, 项)` | 末尾加一个 | 改 |
| `插入(表, 位, 项)` | 插到指定位置 | 改 |
| `移除(表, 项)` | 删掉某个值 | 改 |
| `弹出(表)` / `弹出(表, 位)` | 拿走并返回 | 改 |
| `排序(表)` | 返回排好序的新列表 | 不改 |
| `倒序(表)` | 返回倒过来的新列表 | 不改 |
| `包含(表, 项)` | 在不在里面 → 布尔 | — |
| `连接(表, 分隔)` | 连成一条文字 | — |

## 字典

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `所有标签(字)` | 所有标签 → 列表 | `所有标签({"a":1,"b":2})` | `[a, b]` |
| `所有值(字)` | 所有值 → 列表 | `所有值({"a":1,"b":2})` | `[1,2]` |
| `有标签(字, 标签)` | 有没有这个标签 | `有标签({"a":1}, "a")` | `真` |
| `删标签(字, 标签)` | 删掉一个标签 | — | — |

## 字符串

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `分割(文字, 分隔)` | 按分隔拆成列表 | `分割("a,b,c", ",")` | `[a, b, c]` |
| `替换(文字, 旧, 新)` | 替换 | `替换("abc", "b", "X")` | `"aXc"` |
| `查找(文字, 子串)` | 找位置（从 0 数） | `查找("abc", "b")` | `1` |
| `去空白(文字)` | 去掉首尾空白 | `去空白("  hi ")` | `"hi"` |
| `大写(文字)` | 转大写 | `大写("abc")` | `"ABC"` |
| `小写(文字)` | 转小写 | `小写("ABC")` | `"abc"` |
| `开头是(文字, 前)` | 是不是这样开头 | `开头是("你好", "你")` | `真` |
| `结尾是(文字, 后)` | 是不是这样结尾 | `结尾是("abc", "c")` | `真` |

> 💡 给变量起名时，尽量避开上面这些函数名。CNplus 允许重名（会用你的变量盖住内置函数），但那样内置函数就用不了了。

## 练一练

写一个程序：把 `"  你好 世界  "` 先 `去空白`，再 `分割` 成两个词，最后打印出来。

<details>
<summary>参考答案</summary>

```cnp
设 句子 = 去空白("  你好 世界  ")
设 词们 = 分割(句子, " ")
打印(词们)              # [你好, 世界]
```

> **解析**：分两步——先 `去空白` 去掉首尾空格，得到 `"你好 世界"`；再 `分割(句子, " ")` 按空格切成两段，得到一个列表 `["你好", "世界"]`。两个函数都不改原字符串，而是**返回新结果**，所以要用 `设` 接住。

</details>

---

<details>
<summary>进阶：对照 Python</summary>

CNplus 的内置函数大多是 Python 内置/标准函数的**中文别名**：

| CNplus | Python |
|---|---|
| `打印(x)` | `print(x)` |
| `类型(x)` | `type(x)` |
| `文本(x)` | `str(x)` |
| `整数(x)` | `int(x)` |
| `小数(x)` | `float(x)` |
| `长度(x)` | `len(x)` |
| `范围(…)` | `range(…)` |
| `随机数(小, 大)` | `random.randint(小, 大)`（要先 `import random`） |
| `绝对值(x)` | `abs(x)` |
| `最大(…)` / `最小(…)` | `max(…)` / `min(…)` |
| `求和(表)` | `sum(表)` |
| `四舍五入(x, n)` | `round(x, n)` |
| `平方根(x)` | `x ** 0.5` 或 `math.sqrt(x)` |
| `大写(s)` / `小写(s)` | `s.upper()` / `s.lower()` |
| `去空白(s)` | `s.strip()` |
| `分割(s, 隔)` | `s.split(隔)` |
| `替换(s, 旧, 新)` | `s.replace(旧, 新)` |

规律：CNplus 把 Python 里「对象.方法」的形式（`s.upper()`）改成了「函数(对象, …)」（`大写(s)`），读起来更像中文的「大写(s)」而不是「s 自己大写」。CNplus 两种都能用（`大写(s)` 或 `s.大写()`），Python 只有点调用。

</details>
