# 运行程序的几种方式

> 同一份 CNplus 代码，有好几种跑法。这篇一次讲全——各有各的用场，按场景挑就行。

## 总览

| 方式 | 入口 / 命令 | 什么时候用 |
|---|---|---|
| VSCode 里按 F5 | 编辑器右上角 ▶ 按钮 | **日常写代码**，最常用 |
| 树遍历运行 | `cnp 运行 x.cnp` | 命令行里快速跑一个 |
| Python 转译 | `cnp 运行 --python x.cnp` | 要借 pip 库时 |
| 编译成 `.py` | `cnp 编译 x.cnp` | 生成独立文件，发给别人 |
| 编译成 `.js` | `cnp 编译 x.cnp --js` | 想在网页 / node 里跑 |
| 交互 REPL | `cnp 交互` | 随手试一小段代码 |
| 在线运行器 | [cnplus.org/playground](https://cnplus.org/playground) | 零安装，浏览器直接写 |

一个意思：**同一份源码，换着法子跑，结果一样**。这是 CNplus 的招牌——后端可插拔，加后端不用改前端。

## VSCode 里按 F5（日常首选）

写代码时，直接在编辑器右上角点 ▶，或按 F5。装扩展、信任工作区的步骤见[开始](../教程/00-开始.md)。这是平时最顺手的。

## 命令行：`cnp 运行`（树遍历）

```bash
cnp 运行 我的程序.cnp
```

直接解释执行，启动快、报错精准。这是最基础的后端。

## Python 转译：`cnp 运行 --python` 和 `cnp 编译`

```bash
cnp 运行 --python 我的程序.cnp   # 转译成 Python 再执行
cnp 编译 我的程序.cnp             # 生成独立的 我的程序.py
```

两种用途：

- `--python`：程序里用了 `导入`（借 Python 库）时，**必须**用这个后端。详见[借用 Python 库](../教程/04-让程序活起来/03-借用Python库/01-教程.md)。
- `编译`：生成一个**自包含**的 `.py`，不依赖 CNplus，拷到任何装了 python3 的电脑都能跑。

## JS 转译：`cnp 编译 --js`

```bash
cnp 编译 我的程序.cnp --js        # 生成 我的程序.js
node 我的程序.js                   # node 里跑
```

生成自包含的 JavaScript，**node 和现代浏览器都能跑**。什么时候用？

- 想把程序跑在**网页里**（比如挂到自己的网站）
- 目标机器**没有 Python 环境**，但能跑 JS

它和树遍历、Python 转译**三后端行为一致**（黄金语料 19 组逐字一致）。

**两个边界要知道**：

- ⚠️ **JS 后端 v1 不支持 `导入`**。程序里用了 `导入 "math"` 之类的，编译成 JS 会报错（中文提示会说清）。想用 pip 库，就用 Python 转译，别用 JS。
- 数字语义两处（进阶，一般遇不到）：
  - 整数超过 ±2⁵³−1（约 9000 万亿）会**主动报错**——JS 会悄悄失真，CNplus 拒绝。
  - `4 / 2` 仍是 `2.0` 小数，和树遍历一致。

## 交互 REPL：`cnp 交互`

不建文件，输入一行立即执行，适合**随手试一小段代码**：

```
$ cnp 交互
CNplus 交互模式 —— 输入代码立即执行；输入「退出」或 Ctrl-D 离开
cnp> 1 + 1
2
cnp> 设 x = 10
cnp> x * 2
20
cnp> 打印(@"x 是 {x}")
x 是 10
cnp> 退出
```

几个要点：

- **表达式自动回显**：敲 `1 + 1` 直接看到 `2`，不用写 `打印`。赋值语句（`设 x = 10`）则安安静静不回显。
- **变量 / 函数 / 类跨行保留**：前面定义的，后面还能用（持久环境）。
- **多行块：空行结束**。写 `函数`、`类`、`如果`、`循环` 这类开头，回车后会自动进入续行模式；**写完按一个空行结束**。这是新手最容易懵的地方——写个函数，按回车发现还在缩进里，别慌，再按一次回车（空行）就结束了：

```
cnp> 函数 平方(数)
...     返回 数 * 数
...                    ← 这里按空行，结束定义
cnp> 平方(5)
25
```

- **错误不致命**：写错了会打印中文诊断，然后回到提示符继续，不会整个退出。
- **退出**：输入 `退出`，或按 Ctrl-D。

## 在线运行器：浏览器里直接写

打开 [cnplus.org/playground](https://cnplus.org/playground)，**不装任何东西**，浏览器里直接写 CNplus、直接跑。它是 Pyodide 跑的树遍历后端，语法和本地完全一致，还支持把代码生成分享链接（URL 里带代码）。

**零安装试玩**：还没装本地环境的，先去 playground 玩玩，觉得有意思了再按[开始](../教程/00-开始.md)装本地环境。

## 怎么选

- **正在写代码、边写边调** → VSCode 按 F5
- **想快速验证一小段** → `cnp 交互`，或 playground
- **程序要借 Python 库** → `cnp 运行 --python`
- **要发给没装 CNplus 的人** → `cnp 编译`（生成 .py）或 `cnp 编译 --js`（生成 .js）
- **想在网页里跑** → `cnp 编译 --js`
