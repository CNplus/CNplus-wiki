# 关键字与别名

> CNplus 的关键字都有中文别名，用你顺口的那个，效果完全一样。
> 每组第一个是推荐写法。

## 全角自动转半角

写中文时顺手用了全角标点也没关系，CNplus 会自动转成半角：

| 全角 | 转成 |
|---|---|
| `，` `（` `）` `：` | `,` `(` `)` `:` |
| `　`（全角空格） | ` `（半角空格） |
| `＋` `－` `＊` `／` `＝` | `+` `-` `*` `/` `=` |
| `＜` `＞` `％` `！` | `<` `>` `%` `!` |
| `【` `】` | `[` `]` |
| `“` `”` `‘` `’` | `"` `"` `'` `'` |
| `＠` | `@` |

所以 `打印（1，2）` 和 `打印(1, 2)` 完全一样。

> 💡 全角转半角只影响语法。**字符串里的全角标点不受影响**——那是你的数据，不是语法。

## 成员方法（点调用）

同一个内置函数，有两种写法——像「挂」在集合上点出来：

```cnp
设 名单 = ["小明", "小红"]

打印(名单.包含("小明"))     # 真   —— 读作「名单：包含小明吗」
打印(包含(名单, "小明"))     # 真   —— 读作「名单里有没有小明」
```

两种写法**完全等价**，`名单.包含(x)` 就是 `包含(名单, x)`。列表、字典、字符串上支持点调用的那部分内置函数都能点调用（完整清单见下）：

```cnp
设 名单 = ["小明", "小红"]
设 原文字 = "甲😀乙"

名单.追加("小刚")            # 等价于 追加(名单, "小刚")
打印(名单.长度())             # 等价于 长度(名单)，得 3
打印("hello".大写())          # 等价于 大写("hello")，得 HELLO
打印(原文字.倒序())           # 乙😀甲
打印(倒序(原文字))            # 乙😀甲，和上一行完全等价
```

### 能点调用的完整清单

36 个内置函数里，**有 21 个**挂在列表/字典/字符串上、支持点调用（`对象.函数(…)` 等价于 `函数(对象, …)`）：

| 类别 | 能点调用的函数 |
|---|---|
| 列表 | `追加` `插入` `移除` `弹出` `排序` `倒序` `包含` `连接` `长度` |
| 字典 | `所有标签` `所有值` `有标签` `删标签` `长度` |
| 字符串 | `分割` `倒序` `替换` `查找` `去空白` `大写` `小写` `开头是` `结尾是` `长度` |

（`倒序` 同时适用于列表和文字，`长度` 同时适用于列表/字典/字符串；它们都是各算一个内置函数。清单按不同类型重复列出适用位置，但 36 / 21 / 15 的函数数量不重复计算。）

**其余 15 个只能函数式调用，不能点**：`打印` `询问` `询问数值` `类型` `文本` `整数` `小数` `范围` `随机数` `绝对值` `最大` `最小` `求和` `四舍五入` `平方根`——它们不挂在某个具体的东西上，是「全局动作」或「类型转换」，所以没有 `x.打印()` 这种写法。

为什么有两种写法？两个语感各有自然场景：

- `名单.包含(小明)` —— 主语在前，像「问名单：包含小明吗」；英文代码读惯的人、以及用类方法（`学生.名片()`）的人，顺手就用这种
- `包含(名单, 小明)` —— 先说操作，像「名单里有没有小明」；纯中文语感的人觉得这个更顺

两种写法**不强求统一**，用哪个都行。其中 `名单.包含(x)` 跟类的方法（`学生.名片()`）同形，所以用类多的人更推荐这种——一套心智模型通用。

## 遍历的两种语序

遍历有两种语序，效果一样：

```cnp
设 成绩 = {"小明": 85, "小红": 92}

遍历 成绩 每个 名字    # 自然中文：集合在前、名字在后
    打印(名字)

对于 名字 在 成绩      # 英文习惯：照 for x in y 语序
    打印(名字)
```

- `遍历 成绩 每个 名字` 读作「遍历成绩的每个名字」，自然中文，是推荐写法
- `对于 名字 在 成绩` 是英文 `for x in y` 的语序，为习惯英文的人保留（`对每个` 是 `对于` 的别名）

两种语序能混用，解析成同一个遍历语句，行为完全一致。
